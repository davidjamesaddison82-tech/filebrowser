HarmonyByrd HQ for Windows version 1.1

Install and use HarmonyByrd HQ on this laptop. You won't need any programming knowledge.

HQ runs only on this computer. You open it in your browser at http://localhost:3210. Other computers, your local network and the internet cannot reach it. Your records are never uploaded anywhere.

If version 1 stopped at "nothing listens on a non-loopback interface": extract this version 1.1 package and double-click Install HarmonyByrd HQ again. Nothing needs to be removed first. Version 1.1:
  • backs up your database first;
  • proves it is still the complete preserved database (the 38 restoration checks) and keeps it exactly as it is;
  • never restores over it;
  • leaves your Archive and Backups untouched;
  • runs every check again, now treating Ubuntu's and WSL's own loopback-only DNS services correctly;
  • finishes by issuing your founder passphrase.

What you need

  • Windows 11 and an account that can approve an administrator prompt (this is needed once).
  • At least 10 GB of free disk space. 8 GB of memory or more is recommended.
  • An internet connection for the first installation. It downloads public software only: Ubuntu Linux, PostgreSQL 16 and Node.js.
  • Your verified preservation archive, hq-preservation-2026-11-21-v1.zip. The installer looks for it in Downloads\HarmonyByrd HQ first. If it isn't there, the installer asks you to choose it.

What gets installed, and why

HQ is built from Linux software: its PostgreSQL 16 database and its web application. Windows runs Linux software through a built-in, free Microsoft feature called WSL 2 (Windows Subsystem for Linux).

The installer turns WSL 2 on if it is off, then creates a private Linux system used only by HQ, named HarmonyByrdHQ. You do not need Docker. You do not need to install PostgreSQL or Node.js on Windows yourself, and you never have to type Linux commands.

Install

1. Unblock and extract the package. Right-click HarmonyByrd-HQ-Windows-v1.1.zip and choose Properties. Tick Unblock if it is shown, then click OK. Then right-click the zip, choose Extract All…, and extract it, for example into Downloads\HarmonyByrd HQ.
2. In the extracted folder, double-click Install HarmonyByrd HQ. If Windows shows "Windows protected your PC", click More info and then Run anyway. The package is checked against its checksums before anything is installed.
3. If WSL is not yet turned on, Windows asks for permission. Click Yes. When the window says so, restart Windows, then double-click Install HarmonyByrd HQ again. It carries on from where it stopped.
4. Wait. The installation takes 20–40 minutes. It:
  • checks your preservation archive's SHA-256;
  • copies the archive into a read-only Archive folder and unpacks it there;
  • downloads and checks Ubuntu, then installs PostgreSQL 16 and HQ;
  • restores all 1,581 development records exactly as preserved;
  • runs the 38 restoration checks and the security checks;
  • makes the first backup.
The window shows each step. Every check must pass, or the installation stops and tells you why.
5. Save your founder passphrase. At the end, the window shows a new passphrase once. Copy it into your password manager before you press Enter. It is not saved in any file. If you lose it, use New founder passphrase from the Start menu.
6. Your browser opens HQ. Sign in with the name founder and that passphrase.

Your records stay on disk when HQ is stopped, when Windows restarts, and when HQ is updated.

Backups

  • When: every time you use Stop HarmonyByrd HQ, and every night at 2:15 am while HQ is running. If the laptop was off at 2:15 am, the backup runs the next time HQ starts. You can also back up at any time from the Start menu.
  • Checked: each backup is test-restored and checked before it is kept. A backup that does not restore cleanly is not kept, and you are told.
  • Where: C:\Users\<you>\HarmonyByrdHQ\Backups. Files are named hq-<date>T<time>Z.dump, each with a .sha256 checksum file. They are kept for 35 days.
  • Keep a copy elsewhere: copy the Backups folder to a USB drive from time to time. A backup that exists only on this laptop is lost with the laptop.
Protect the laptop. The backups are ordinary database files, so anyone who has the laptop's disk could read them. Turn on Device encryption or BitLocker: Settings → Privacy & security → Device encryption. The HarmonyByrdHQ folder is not inside OneDrive and is not uploaded. Do not move it into OneDrive, Dropbox or Google Drive.

Restoring a backup

  1. Start menu → HarmonyByrd HQ → Restore HarmonyByrd HQ from a backup.
  2. Choose the backup file and type RESTORE.

HQ then backs up the current database, checks the chosen backup, and only then swaps it in. The database it replaced is also kept inside HQ, so nothing is thrown away. Afterwards it runs the checks again.

Checking HQ

Start menu → HarmonyByrd HQ → Check HarmonyByrd HQ confirms that:

  • HQ is reachable from this computer only;
  • every file in the Archive (including the 43 captured original documents) still matches its SHA-256 checksum;
  • the records' seals, hash chain, citations and quotations are intact;
  • the 38 restoration checks still equal the preserved database (skip this one once you have added records on purpose);
  • a read-only AI identity can read but cannot write or act as founder;
  • the per-token rate limit works;
  • a backup has been made in the last 26 hours.

A report is saved in the Logs folder.

Security

  • HQ and its database listen only on this computer's own loopback address. Windows passes localhost:3210 to HQ and to nothing else. No firewall rule is added and no port is opened. The installer and Check HarmonyByrd HQ both confirm this.
  • Credentials are created fresh on this laptop during installation, and none is inside the package:
    • a random database password and a random session secret, readable only inside HQ's Linux system;
    • your founder passphrase, of which only a hash is stored.
  • The Linux system cannot start Windows programs.
  • Your requirements, founder decisions, acceptance records and evidence are restored exactly. The 38 checks prove that before HQ is first opened.

Claude and ChatGPT (later)

HQ's REST API and MCP interface are installed unchanged, at http://localhost:3210/api/v1 and http://localhost:3210/api/mcp.

Three separate read-only AI identities are ready: researcher, qa-auditor and chatgpt. None has a token yet, so no AI can connect until you decide.

When you do, issue a token on HQ's AI & API access screen, one per AI. Leave only read ticked, and enter an expiry, for example 90 days. The token is shown once, and you can revoke it on the same screen at any time. Each token is limited to 120 requests a minute.

  • An AI tool running on this laptop (for example Claude Code) can use the localhost address directly.
  • Cloud services (Claude's Managed Agents, ChatGPT) cannot reach localhost. They need a tunnel or a public address. That is a separate decision, described in docs/HOSTING.md in the HQ source.

Updating HQ

When you receive a newer Windows package, extract it and double-click Install HarmonyByrd HQ again. It:

  • backs up first;
  • installs the new application;
  • never replaces your database;
  • runs the checks.

It asks whether you want a new founder passphrase. Answer N to keep your current one.

Uninstalling

Start menu → HarmonyByrd HQ → Uninstall HarmonyByrd HQ, then type REMOVE. It makes a final backup, then removes HQ's Linux system and the shortcuts. Your Backups and Archive folders are kept.

Start says HQ did not answerUse Stop, then Start. If that fails, run Check HarmonyByrd HQ and keep its report from the Logs folder.
"reachable from beyond this computer"Use Stop. This should not happen with Windows' standard WSL settings. If you have changed WSL's networking settings (a .wslconfig file in your user folder), undo that change.
Port 3210 already in useAnother program is using it. Close that program, then Start again.
Forgotten passphraseStart menu → New founder passphrase.

Every installation run writes a full log to the Logs folder.
